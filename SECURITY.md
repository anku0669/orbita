# Security Policy

ORBITA is a research prototype. Do not deploy it as a multi-user service or use it to execute untrusted tools without additional isolation and review.

Report suspected vulnerabilities through GitHub's private vulnerability reporting feature where enabled. Include affected commit, impact, reproducibility steps, and a suggested mitigation. Avoid sharing secrets or third-party personal data.

Supported release security work planned: dependency review, SBOM, signed artifacts, build provenance, native platform tests, filesystem symlink hardening, and independent security assessment.
